# Trusted Computing Integrity Platform

A software prototype demonstrating Trusted Computing concepts using real SHA-256 integrity measurements.

## Features

- SHA-256 file measurement
- Trusted baseline creation
- File integrity verification
- Modified file detection
- Missing file detection
- Trust decision
- Access control
- Security event logging
- Trusted-state recovery
- Web dashboard

## Technologies

- Python
- FastAPI
- HTML
- CSS
- JavaScript
- SHA-256
- REST API

## Trusted Computing Concepts

The project demonstrates the following Trusted Computing concepts:

1. Measurement
2. Trusted Baseline
3. Integrity Verification
4. Trust Decision
5. Access Control
6. Security Monitoring
7. Recovery
